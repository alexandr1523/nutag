# Аудит требований Nutag

Этот файл связывает исходную функциональную постановку с текущим состоянием проекта. Исходные документы не удаляются и не переписываются как история требований, но текущий статус требований определяется здесь, в `IMPLEMENTATION_PLAN.md` и в `docs/DECISIONS.md`.

## Статусы

- `active` — требование актуально.
- `implemented` — требование реализовано в текущем MVP.
- `partial` — реализовано частично.
- `changed` — требование изменено более поздним решением.
- `later` — актуально, но не в ближайшей очереди.
- `not in MVP` — не входит в текущий MVP.
- `legacy` — историческое требование, больше не источник истины.
- `needs review` — требует уточнения перед реализацией.

## Требования по областям

### Закупки

| Требование | Статус | Комментарий |
|---|---|---|
| Фиксировать закупку с датой, поставщиком, закупившим, временем, транспортом и строками. | `implemented` | Базовый сценарий реализован. |
| Строки закупки: ингредиент, упаковка, расходник, количество, цена, сумма, срок годности. | `partial` | Ингредиенты, упаковка и расходники поддержаны; контроль и UI продолжают развиваться. |
| Редактирование и удаление прошлых закупок. | `partial` | Реализовано для неиспользованных закупок; изменение состава строк ограничено. |

### Заготовки

| Требование | Статус | Комментарий |
|---|---|---|
| Заготовки как отдельные внутренние полуфабрикаты с остатком и себестоимостью. | `implemented` | Создание, выбранные партии ингредиентов и остатки реализованы. |
| Отходы/обрезь по ингредиентам. | `implemented` | Учитываются на уровне строк ингредиентов заготовки. |
| Создание заготовок из других заготовок. | `later` | Требование добавлено в backlog, но не в ближайшей очереди. |
| Автоподстановка ингредиентов по выбранной заготовке. | `later` | Отложено до рецептур. |

### Производство

| Требование | Статус | Комментарий |
|---|---|---|
| Производственная партия списывает выбранные партии ингредиентов и заготовок. | `implemented` | Сервисные проверки и UI-разделение позиции/партии реализованы. |
| Фиксация трудозатрат. | `implemented` | Нельзя сохранять производственную партию без положительных трудозатрат. |
| Фактический выпуск готовой продукции. | `changed / implemented` | Реализован как нефасованный выпуск, фасовка вынесена отдельно. |
| Отходы производства. | `rejected` | Пользователь отказался от этого сценария; отходы учитываются в заготовках. |
| Измерение скорости производства. | `later` | Есть в backlog для понимания мощности. |

### Фасовка ГП

| Требование | Статус | Комментарий |
|---|---|---|
| Отдельное превращение нефасованного остатка в фасованную партию. | `implemented` | Реализована страница и сервис фасовки. |
| Списание выбранной партии упаковки. | `implemented` | Проверяется партия упаковки, единица и остаток. |
| Удаление ошибочной фасовки. | `implemented` | Разрешено только если фасовка не использована в заказах. |
| Редактирование фасовки. | `rejected for MVP` | Безопасный workflow — удалить неиспользованную фасовку и создать новую. |

|---|---|---|
