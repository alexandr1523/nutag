# 02. Журналы, справочники и сущности

> Важно: это исходная постановка. Текущий статус требований см. в `docs/REQUIREMENTS_AUDIT.md`, причины изменённых и отклонённых решений — в `docs/DECISIONS.md`, оперативную очередь работ — в `IMPLEMENTATION_PLAN.md`.

## 1. Справочники

Система должна поддерживать справочники:

- продукты;
- варианты / начинки;
- ингредиенты;
- упаковка;
- расходники;
- единицы измерения;
- этапы производства;
- статусы заказов;
- статусы оплат;
- способы получения;
- причины списаний;
- категории постоянных расходов;
- оборудование.

## 2. Закупки

Каждая закупка должна фиксироваться отдельно.

По каждой закупке нужно хранить:

- дата закупки;
- поставщик / магазин;
- кто закупал;
- сколько времени потрачено на закупку;
- транспортные / доставочные расходы, если есть;
- комментарий;
- список купленных позиций.

По каждой позиции закупки нужно хранить:

- что куплено;
- тип позиции: ингредиент, упаковка, расходник;
- единица измерения;
- количество;
- цена за единицу;
- сумма;
- срок годности, если применимо;
- комментарий.

## 3. Остатки сырья, упаковки и расходников

Система должна показывать остатки по каждому сырью, упаковке и расходнику:

- начальный остаток;
- закуплено;
- использовано в заготовках;
- использовано в финальном производстве;
- списано;
- остаток на конец;
- средневзвешенная цена;
- стоимость остатка.

Должен быть контроль отрицательных остатков.

## 4. Рецептуры

Рецептуры должны храниться отдельно от фактического производства.

По рецептуре нужно хранить:

- продукт;
- версия рецепта;
- активная версия или нет;
- ингредиент / материал;
- единица измерения;
- количество на выбранную базу расчёта;
- комментарий.

Рецепты могут меняться, поэтому должна быть возможность вести версии рецептур.

## 5. Заготовки / внутренние полуфабрикаты

Заготовка — это внутренний полуфабрикат, который может быть произведён заранее и использован в одной или нескольких будущих партиях.

Примеры заготовок:

- мясная заготовка свинина+говядина;
- фарш;
- начинка для бууз;
- картофельная начинка;
- тесто;
- нарезанные овощи;
- суповая основа.

По заготовке нужно хранить:

- ID заготовки;
- дата подготовки;
- наименование заготовки;
- какие ингредиенты использованы;
- фактический расход ингредиентов;
- стоимость ингредиентов;
- какие этапы работ выполнены;
- время подготовки;
- стоимость труда;
- прочие прямые расходы, если есть;
- фактический выход;
- себестоимость единицы заготовки;
- остаток заготовки;
- остаточная стоимость;
- срок хранения;
- комментарий.

## 6. Производственные партии

Каждая готовка должна фиксироваться как отдельная производственная партия.

По партии нужно хранить:

- ID партии;
- дата производства;
- продукт;
- версия рецепта;
- плановый объём;
- фактический выход;
- статус;
- комментарий.

Партия может использовать:

- обычные ингредиенты;
- упаковку;
- расходники;
- заготовки / внутренние полуфабрикаты;
- трудозатраты по этапам;
- долю оборудования через амортизацию;
- долю постоянных расходов, если это включено в расчёт.

## 7. Этапы производства

По каждому дню производства и по каждой партии нужно фиксировать этапы и время.

По этапу нужно хранить:

- дата;
- ID партии или ID заготовки;
- продукт / заготовка;
- этап;
- кто делал;
- время или количество минут;
- стоимость часа;
- стоимость времени;
- комментарий.

Этапы могут включать:

- закупка;
- подготовка ингредиентов;
- разделка / фарш;
- замес теста;
- подготовка начинки;
- лепка;
- фасовка;
- заморозка;
- уборка;
- администрирование заказов;
- выдача;
- доставка.

## 8. Фактический расход ингредиентов и заготовок

По каждой партии нужно фиксировать фактический расход.

Для обычного сырья и упаковки:

- ID партии;
- продукт;
- ингредиент / материал;
- единица измерения;
- фактический расход;
- цена для расчёта;
- стоимость расхода;
- комментарий.

Для заготовок:

- ID партии;
- ID заготовки;
- наименование заготовки;
- количество использованной заготовки;
- себестоимость единицы заготовки;
- стоимость использованной заготовки;
- комментарий.

## 9. Выход готовой продукции

По каждой партии нужно фиксировать фактический выход продукции:

- ID партии;
- продукт;
- фасовка;
- количество упаковок;
- количество килограммов;
- дата производства;
- дата заморозки;
- рекомендуемый срок реализации;
- дата “использовать до”;
- место хранения;
- комментарий.

## 10. Заказы и продажи

По каждому заказу нужно хранить:

- дата заказа;
- клиент;
- контакт;
- продукт;
- фасовка;
- количество упаковок;
- количество килограммов;
- цена по прайсу;
- скидка, если есть;
- фактическая цена продажи;
- сумма заказа;
- статус оплаты;
- дата оплаты;
- способ получения;
- окно выдачи;
- статус заказа;
- повторный заказ или нет;
- комментарий клиента.

Статусы заказа должны позволять отличать новые, подтверждённые, оплаченные, готовые, выданные, отменённые и проблемные заказы.

## 11. Оплаты

Нужно учитывать:

- ID оплаты;
- дата оплаты;
- ID заказа;
- сумма оплаты;
- способ оплаты;
- комиссия, если есть;
- сумма после комиссии;
- комментарий.

## 12. Доставка и выдача

Нужно учитывать доставку и выдачу, потому что они могут съедать экономику.

По доставке / выдаче нужно хранить:

- дата;
- ID заказа;
- способ получения;
- адрес / район;
- время на доставку или выдачу;
- прямые расходы на доставку;
- платная или бесплатная доставка;
- плата клиента за доставку;
- результат доставки;
- комментарий.

## 13. Клиенты и повторные покупки

Нужно фиксировать повторный интерес и повторные покупки.

По клиентам нужно видеть:

- первый заказ;
- последний заказ;
- количество заказов;
- сумма заказов;
- повторный клиент или нет;
- что покупал повторно;
- комментарии.

## 14. Списания

Нужно учитывать списания:

- брак;
- пробники;
- личное потребление;
- просрочка;
- порча;
- корректировка остатка;
- другое.

Списания могут относиться к:

- сырью;
- упаковке;
- расходникам;
- заготовкам;
- готовой продукции.

## 15. Постоянные расходы

Нужно вести постоянные расходы:

- дата;
- месяц;
- категория;
- описание;
- сумма;
- денежный расход или управленческий расход;
- включать в безубыточность или нет;
- включать в себестоимость или нет;
- комментарий.

Категории постоянных расходов:

- электричество;
- вода;
- реклама;
- моющие средства;
- перчатки / расходники;
- интернет / телефон;
- комиссии;
- админ-время;
- прочее.

## 16. Оборудование и инвестиции

Нужно учитывать инвестиции в оборудование.

По оборудованию нужно хранить:

- дата покупки;
- оборудование;
- стоимость;
- срок использования;
- амортизация за период;
- включать в себестоимость или нет;
- способ распределения;
- для каких продуктов используется;
- остаток до окупаемости;
- комментарий.

Примеры оборудования:

- морозилка;
- мясорубка;
- тестомес;
- весы;
- пароварка / мантоварка;
- контейнеры;
- стол / коврик для лепки;
- вакууматор.
