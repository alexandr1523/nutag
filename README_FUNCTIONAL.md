# Функциональная постановка проекта учёта полуфабрикатов

> Важно: это исходная функциональная постановка. Текущий статус требований см. в `docs/REQUIREMENTS_AUDIT.md`, причины изменённых и отклонённых решений — в `docs/DECISIONS.md`, оперативную очередь работ — в `IMPLEMENTATION_PLAN.md`.

Этот набор файлов предназначен как функциональная постановка для будущей реализации системы учёта домашнего производства полуфабрикатов.

В документах описано только то, что система должна уметь с точки зрения бизнеса и учёта. Технические решения, архитектура, библиотеки, структура кода, GitHub-процессы и детали Streamlit-интерфейса намеренно не описываются.

## Состав документов

1. `01_scope_and_principles.md` — цель системы, границы и базовые принципы учёта.
2. `02_registers_and_entities.md` — какие журналы, справочники и сущности нужно вести.
3. `03_calculation_rules.md` — правила расчёта себестоимости, остатков, маржи, безубыточности и окупаемости.
4. `04_workflows_and_controls.md` — основные рабочие сценарии и контрольные проверки.

## Важное ограничение

В постановку включены только требования и пожелания к функциональности, которые были явно запрошены или подтверждены.
